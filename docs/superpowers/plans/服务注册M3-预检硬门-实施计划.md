## Context

环境降级 M1（carry 去 env）、M2（标签解析链 + 凭证去 env）已完成。M3 是 §8.0 决策 5 的落地：**UI/JWT、access token、webhook 三条派发路径统一预检硬门**——把现在「告警不拦截」的缺项（地址/登录口/身份/账户缺失、账户歧义、标签不可解析）升级为派发前 409，错误时机从步骤级报错前移。范围仅后端；前端契约消费与环境控件退场归 M4；无数据库迁移。

## 硬门七码（§8.5 错误码表）

`env_unspecified`（标签不可解析，根因语义改写）｜`env_mixed`｜`address_missing`｜`login_missing`｜`identity_missing`｜`account_missing`｜`account_ambiguous`

detail 必带上下文：标签名/服务/系统/身份。

**提示不拦截**（保持现状）：
- 账户/身份 env 与执行标签不同（凭证解耦，`envWarnings` 提示，执行期 401 自然暴露）；
- `out_of_scope_targets` 只记录不拦截（webhook v4 §7.1/D15）；
- `scope_missing` 仍置 `scheme_valid=False`（真拒在 403 范围闸）；
- suites validate 保持 warn 聚合语义（离线校验面，HTTP 恒 200）。
