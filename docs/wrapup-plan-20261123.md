## 0. 总原则与依赖图

1. **价值优先**:唯一在档用户可见功能(注入溯源)先于内部质量项。
2. **先删后重构**:自举链(B6/C3/C11)删 legacy 链排在 C1 dispatcher 重构之前
   ——删链直接消除 run_dispatcher 的双路径分支,缩小 C1 重构面。
3. **新测试 server 链优先**:凡新写执行链 e2e,一律局部覆写
   `EXEC_CHAIN=server`(先例 `test_graph_version_ledger.py:150`),
   不给 28 文件翻链批再加负担。
4. **合并窗口项压低峰**:C5 一次性大 diff、B2 尾项等 A1 拍板后的批间低峰做,
   不与活跃开发并行。

动作,不含架构级变更(不动模块边界、数据流主干、权限模型)。架构级
