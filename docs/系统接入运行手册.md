# 系统接入运行手册（Plate 版本管理）

> 2026-10-12 · 依据：《Plate 版本模型》v1.4、《Plate Release 设计》v4.4、缺口收口计划 P0.4/W16
> 适用：把一个系统从 working ref（按当前规格树）接入版本管理（按修订钉定）。
> 原则：working 优先、渐进接入（缺口收口计划 §0 裁定 1）——不全局回填，按系统逐个走本手册。

## 0. 一次性前置（每环境/每检出做一次）

1. **构件分支底座**（`plate/artifacts` 孤子分支 + worktree 检出）：
   ```bash
   # 已存在则跳过；根提交为空树
   git branch plate/artifacts $(git commit-tree 4b825dc642cb6eb9a060e54bf8d69288fbee4904 -m "plate/artifacts 构件分支根(空树)")
   git worktree add D:/Gimbal/plate-artifacts plate/artifacts
   git push -u origin plate/artifacts      # 必推远端——构件只存本机曾导致整链丢失
   ```
2. **配置构件根**：`src/restart-services.ps1` 已设 `$env:PLATE_ARTIFACTS_PATH = 'D:\Gimbal\plate-artifacts'`；重启后探针：
   ```bash
   curl http://127.0.0.1:8765/api/system/fin/lines
   # ok:true 即通；registry_unavailable = 构件根未配置
   ```
3. **M2 信封入池**（对象池存在 `objects/<m2_hash>.json`，执行可追溯依赖它）：
   ```bash
   PLATE_ARTIFACTS_PATH='D:/Gimbal/plate-artifacts' python scripts/gen_m2.py gen --targets envelope
   ```

## 1. 接入一个系统（六步）

| 步 | 动作 | 命令 / 入口 | 验收 |
|---|---|---|---|
| ① 注册系统树 | `systems/<sys>/` 建树，`system.md` frontmatter 声明 `line: "<线名>"` | 编辑器 + `plate check <sys>` | check 零 finding |
| ② 评审 | 逐对象 `review: draft → reviewed` | `plate review <对象> --set reviewed` 或编辑 frontmatter | draft 清零（带 draft 也能发版，但只进 warnings） |
| ③ 发首修订 | **工作区必须净**（B1 脏树门会拒） | `PLATE_ARTIFACTS_PATH=… plate release <sys> --json` | `success:true`；`plate lines <sys>` 见 `<line>#1`；**push plate/artifacts** |
| ④ 场景钉修订 | 编排器「基本信息 → 版本声明 (meta.plate)」下拉选修订；**批量**用 `scripts/rs3_backfill_meta_plate.py`（演练→备份→--apply→幂等复跑） | 编排器 / 脚本 | 下拉显示已选修订；步骤编辑契约表单页脚「来自 plate · N 个顶层节点」 |
| ⑤ 剥离派生字段 | 已钉修订的场景才需要（binding 派生字段从存储剥离） | `scripts/migrate_strip_binding_fields.py`（同迁移纪律） | 演练 0 项或按预期 |
| ⑥ 执行验证 | 跑一单场景 | 执行详情 | `plate_pins` 出参 = `{"<sys>": "<line>#<n>"}`；正式执行（非预览） |

## 2. 口径速查（三态模型）

| 状态 | 含义 | 执行判定 |
|---|---|---|
| 钉修订 | `meta.plate[sys] = "<line>#<n>"` | 正式执行，可入库（接口全已评审时） |
| working | 按当前规格树 | 预览执行，不计入入库标准；集成任务拒绝 |
| external | 第三方服务（平台服务注册表 `kind=external`，建设中） | 不算预览、不阻塞集成；单独统计，不入基线 |

## 4. 故障排查

| 症状 | 原因 | 处置 |
|---|---|---|
| `/api/system/*/lines` 返回 `registry_unavailable` | plate 进程没有 `PLATE_ARTIFACTS_PATH` | 检查 restart-services.ps1 注入；重启后重探针 |
| release 报脏树 | 源码工作区未净 | 提交/暂存后再发版 |
| release 报 predecessor 无修订 | `system.md` 声明了 `predecessor_line` 但该线无修订 | 先发前驱线，或去掉声明 |
| 编排器表单退化为 JSON | 场景未钉修订且锚点读取失败 / 步骤无锚点 | 检查 `step.endpoint` 与版本声明；external 步骤属正常 |
| 执行详情 `plate_pins` 为 null | 老版本序列化器漏传（已修，2026-10-12） | 更新后端；库列 `executions.plate_pins` 为权威 |
